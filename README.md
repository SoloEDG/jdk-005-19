# 青禾农场

安装：`npm install`

本地启动：`npm run dev`

Docker 启动：`docker compose -p pinru-jdk005-1113 up --build`，打开 http://localhost:18025 。

## 轮作养地

- 每块田有独立的氮磷钾、有机质与连作疲劳，作物按苗期/生长期/结实期消耗不同养分。
- 同科连种累积疲劳（生长变慢、吸收变差），换科轮作与休耕慢慢养回地力。
- 收获残渣送工坊发酵成真实堆肥批次；施肥按配方×用量入土，与肥料品质无关。
- 化肥见效快但本轮失去有机资格；有机 = 未用化肥 + 连续有机轮次 + 本轮施过堆肥，资格随批次与加工品流转，有机订单只收有机份额。
- 本轮养分亏欠一旦累积就无法靠最后一刻施肥抹去；铲除作物不退回已消耗的肥料。
